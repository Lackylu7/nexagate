NexaGate 采用预付费余额。请求按模型、输入 tokens、输出 tokens 和账号分组扣费，余额不足时停止调用。

透明计费

每次请求按输入和输出 tokens 计费，控制台会显示余额、消耗和调用记录，方便你按项目核算成本。

用户怎么控制成本

用户可以按项目创建 API Key，并给每个 Key 单独设置额度。余额或 Key 额度不足时，请求会停止。

适合持续集成

统一的 Base URL、稳定的模型名称和清晰的调用记录，适合接入脚本、应用后端、客服系统和内部工具。
