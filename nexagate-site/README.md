# NexaGate Site

This is the public-facing brand site for NexaGate. It is intentionally separate from the New API console so the open-source gateway can remain the internal engine while customers see NexaGate's product, pricing, and developer documentation first.

Open `index.html` directly in a browser for local preview.

Suggested production split:

- `nexagate.yourdomain.com` for this public site and API requests
- `admin.nexagate.yourdomain.com` for the New API admin console
