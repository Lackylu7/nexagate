认证

所有请求都需要携带控制台生成的 API Key。请只在服务端保存和使用 Key，不要放在浏览器前端或公开仓库里。

Authorization: Bearer sk-ng-your-key

JavaScript SDK

如果你已经在用 OpenAI 风格 SDK，通常只需要替换 apiKey、baseURL 和 model。

最小可运行示例

先用 curl 确认 Key 和余额可用，再把同样的 Base URL 和模型名接入你的服务端代码。

流式输出

需要边生成边显示时，在请求里启用 stream。适合聊天窗口、客服回复和长文本生成。

充值与入账

目前支持扫码付款后提交充值信息。管理员核对到账后会把余额加到你的账号里，控制台充值记录会显示待核对、已入账或已驳回。

价格与扣费

NexaGate 使用预付费余额。每次请求会按输入和输出 tokens 扣费，余额不足时停止调用。

常见错误

状态码含义处理方式
400参数错误检查 model、messages 和 JSON 格式。
401API Key 无效重新创建或轮换 Key。
402余额不足充值后再重试。
403模型未开通换用已开通模型，或联系管理员开通权限。
429请求过于频繁降低并发，或联系管理员提高限额。
500/502服务或上游异常稍后重试；持续出现时带上请求时间联系支持。

安全建议

按项目创建不同 API Key，并设置合理额度。完整 Key 只在创建时显示一次，建议保存到服务端环境变量或密钥管理工具里，不要放进浏览器前端、日志、截图或公开仓库。
